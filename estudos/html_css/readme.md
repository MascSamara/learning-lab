# 🌐 HTML & CSS — Learning Lab

Coleção de exercícios, desafios e projetos desenvolvidos durante meus estudos de **HTML5 e CSS3**, acompanhando principalmente as aulas e conteúdos do curso de **Gustavo Guanabara**.

Esta pasta representa uma etapa prática da minha formação em desenvolvimento web, onde aplico os conceitos aprendidos por meio da construção de páginas e experimentos próprios.

> **Aprender → praticar → experimentar → construir.**

---

## 📌 Sobre a pasta

A pasta `html_css` reúne minha prática com os fundamentos do desenvolvimento web utilizando **HTML5 e CSS3**.

Aqui estão organizados exercícios realizados durante as aulas, desafios propostos e projetos desenvolvidos para colocar em prática os conhecimentos adquiridos.

O objetivo é transformar conceitos teóricos em código e acompanhar minha evolução desde os primeiros elementos HTML até a construção de páginas mais estruturadas e estilizadas.
