# samara-python-lab
🚀 Samara Python Lab

Coleção de scripts em Python voltados ao aprimoramento de lógica de programação, manipulação de dados e resolução de problemas práticos.

📌 Sobre o projeto

Este repositório reúne exercícios e scripts desenvolvidos ao longo da minha jornada de aprendizado em Python.
O objetivo é consolidar fundamentos da programação, praticar resolução de problemas e evoluir continuamente minhas habilidades técnicas.

🧠 Tecnologias utilizadas
Python 3
Biblioteca padrão (input, print, operadores, estruturas de controle)
Manipulação de dados com Python
📂 Estrutura do projeto

Os arquivos estão organizados por scripts independentes, abordando diferentes conceitos:

📌 Entrada de dados (input)
📌 Tipos primitivos
📌 Operações matemáticas
📌 Estruturas condicionais
📌 Laços de repetição
📌 Pequenos projetos práticos (IMC, cálculo de área, tabuada, etc.)
🎯 Objetivos
Desenvolver raciocínio lógico
Praticar resolução de problemas
Evoluir consistência em programação
Criar base sólida para projetos mais avançados
🚧 Próximos passos
Organizar os scripts em pastas por tema
Melhorar a legibilidade dos códigos
Adicionar comentários explicativos
Evoluir para projetos mais complexos (automação, análise de dados, APIs)
