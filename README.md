# 🧪 Learning Lab

> Laboratório pessoal de estudos, experimentação e desenvolvimento em Engenharia de Software.

Este repositório registra minha evolução prática durante minha formação em Engenharia de Software.

Aqui reúno fundamentos, exercícios, experimentos, desafios e projetos desenvolvidos ao longo do meu processo de aprendizagem.

A proposta é transformar conhecimento em prática, documentando minha evolução técnica e construindo uma base sólida para o desenvolvimento de software.

---

## 🎯 Objetivos

- Consolidar fundamentos de programação
- Desenvolver raciocínio lógico e resolução de problemas
- Praticar desenvolvimento web
- Aprender e aplicar boas práticas de Engenharia de Software
- Desenvolver projetos práticos
- Trabalhar com Git e GitHub
- Explorar bancos de dados e APIs
- Experimentar novas tecnologias
- Registrar minha evolução técnica ao longo do tempo
